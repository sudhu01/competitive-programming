# B - 105

- **Time Limit:** 2 seconds
- **Memory Limit:** 976 MB
- **Score:** 200 points
- **Source:** [AtCoder - ABC106 B](https://atcoder.jp/contests/abc106/tasks/abc106_b)

## Problem Statement

The number **105** is quite special: it is **odd** but has exactly **eight positive divisors**.

Your task is to determine how many **odd numbers** with exactly **eight positive divisors** exist between **1** and **N**, inclusive.

---

## Constraints

- **1 ≤ N ≤ 200**

---

## Input

The input is given from standard input in the following format:

```text
N
```

---

## Output

Print the number of odd integers between **1** and **N**, inclusive, that have exactly **eight positive divisors**.

---

## Examples

### Example 1

#### Input

```text
105
```

#### Output

```text
1
```

### Explanation

Among the odd numbers from **1** to **105**, only **105** has exactly eight positive divisors.

---

### Example 2

#### Input

```text
7
```

#### Output

```text
0
```
