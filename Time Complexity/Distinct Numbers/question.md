# Distinct Numbers

## Problem Statement

You are given a list of **n** integers.

Your task is to determine how many **distinct** values appear in the list.

---

## Input

The first line contains a single integer:

```text
n
```

The second line contains **n** integers:

```text
x₁ x₂ ... xₙ
```

---

## Output

Print a single integer: the number of distinct values in the list.

---

## Constraints

- **1 ≤ n ≤ 2 × 10⁵**
- **1 ≤ xᵢ ≤ 10⁹**

---

## Example

### Input

```text
5
2 3 2 2 3
```

### Output

```text
2
```

### Explanation

The distinct values in the list are:

```text
2, 3
```

So the answer is:

```text
2
```
