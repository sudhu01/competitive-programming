# ABC400 Party

- **Time Limit:** 2 seconds
- **Memory Limit:** 1024 MiB
- **Score:** 100 points

## Problem Statement

In the ceremony commemorating **ABC400**, we want to arrange **400 people** in a rectangular formation consisting of **A** rows and **B** columns, with no empty spaces.

You are given a positive integer **A**.

Print the value of a positive integer **B** such that this arrangement is possible.

If no such positive integer **B** exists, print **-1**.


## Constraints

- **1 ≤ A ≤ 400**
- **A** is an integer.


## Input

The input is given from standard input in the following format:

```text
A
```


## Output

Print the value of **B** if it exists; otherwise, print **-1**.


## Examples

### Example 1

#### Input
```text
10
```

#### Output
```text
40
```

---

### Example 2

#### Input
```text
11
```

#### Output
```text
-1
```

---

### Example 3

#### Input
```text
400
```

#### Output
```text
1
```
